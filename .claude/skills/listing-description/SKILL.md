# Listing description

## 1. Gather the facts
Work only from details the agent gives. If any of these are missing, ask once in a single short list, then write with what you have:
- Address or neighborhood, price, property type
- Beds, baths, square footage, lot size, year built
- Top 3–5 features (renovations, views, layout, outdoor space, garage)
- Nearby draws (schools, parks, transit, shopping), only if the agent names them
- Target buyer (first-time, family, downsizer, investor, luxury)
- MLS character limit, if any

## 2. Write
Give the agent:
1. **Three headline options** of 10 words or fewer, each with a different angle (lifestyle, feature, location).
2. **MLS description**: 150–250 words unless a limit is given. Open with the strongest feature, walk through the home in the order a buyer would tour it, and end with a call to action to schedule a showing.
3. **Feature bullets**: 6–10 short bullets for flyers and websites.
4. **Short version**: 280 characters or fewer, for portals and texts.

## 3. Rules
- **Fair housing:** never describe the people a home suits by race, color, religion, sex, disability, familial status, national origin, or other protected class. Describe the property, not the buyer. Avoid phrases like "perfect for young families", "walking distance to church", "exclusive neighborhood", "master bedroom" (use "primary bedroom"), "ideal for singles", or "no wheelchairs". Use "close to parks", "flexible floor plan", "spacious primary suite" instead.
- Never invent features, square footage, school ratings, or HOA details. Mark anything uncertain as `[confirm]`.
- Specific beats vague: "quartz counters and a 6-burner gas range", not "gourmet kitchen".
- Limit superlatives and skip clichés like "won't last", "must see", "nestled", "boasts".
- Write in plain, warm, active voice.
